INTER PROCESS COMMUNICATION

Process

A process is a program that is currently being executed by the computer. For example, when we open a browser, music player, or calculator, each running application can have one or more processes.

Inter-Process Communication (IPC)

Inter-Process Communication (IPC) is a mechanism provided by the operating system that allows different processes to exchange data and communicate with each other.

Normally, each process has its own memory space. IPC provides methods through which processes can safely exchange information.

Need for IPC

IPC is required for:

* Sharing data between processes
* Sharing system resources
* Coordinating different processes
* Synchronizing processes
* Improving performance by dividing work between processes

Example

A web browser may communicate with another process that handles network operations. The processes exchange information using an IPC mechanism.

Main IPC Techniques

The commonly used IPC techniques are:

1. Shared Memory
2. Message Passing
3. Pipes
4. FIFO / Named Pipes
5. Signals
6. Sockets


signals
## 1. SIGNALS

### Definition

A signal is an Inter-Process Communication (IPC) mechanism used to notify a process that a particular event has occurred.

Signals are software notifications sent to a process by the operating system or another process. They are mainly used for process control and event handling.

### Working

1. A process receives a signal when a particular event occurs.
2. The operating system delivers the signal to the process.
3. The process identifies the received signal.
4. The process performs a predefined action when the signal is received.

### Examples of Signals

- SIGINT: Terminates a process when the user presses Ctrl + C.
- SIGKILL: Immediately terminates a process.
- SIGSTOP: Stops the execution of a process.
- SIGTERM: Requests a process to terminate.
- SIGALRM: Generates a signal when a timer expires.

### Advantages

- Helps in process communication.
- Supports event handling.
- Allows processes to be interrupted or terminated.
- Provides a simple mechanism for process control.

## 2. SOCKETS

### Definition

A socket is an Inter-Process Communication (IPC) mechanism that allows two processes to communicate with each other.

Sockets support communication between processes running on the same computer or on different computers connected through a network.

They are commonly used in client-server applications.

### Working

Socket communication generally follows a client-server model.

1. The server creates a socket.
2. The server waits for connection requests from clients.
3. The client creates a socket and connects to the server.
4. Once the connection is established, both processes can exchange data.
5. After communication is completed, the connection is closed.

### Examples

- Web browsers communicating with web servers.
- Chat applications.
- Online gaming.
- File transfer applications.

### Advantages

- Supports communication between different computers.
- Allows data exchange over networks.
- Useful for client-server applications.
- Supports real-time communication.

In simple words: A socket is an endpoint that allows two processes to send and receive data, either on the same computer or over a network.
